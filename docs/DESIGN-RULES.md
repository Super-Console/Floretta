# 设计规矩

以后改界面先对照这里。审查清单在 `docs/REVIEW-WORKFLOW.md`。和冒烟冲突时，冒烟优先。

1. **一个功能一个可见入口。** 快捷键不算入口。设置在宽屏只走侧栏「设置」，窄屏只走设置页签。首页不再放齿轮。⌘, 可以留。
2. **每个全屏页面都能离开。** 编辑器左上返回在 Mac、iPad、iPhone 都在。Zen 有退出。
3. **工具栏先用图标。** 撤销、重做、删除、插入、分享、更多用 SF Symbol，无障碍名称用中文。菜单行是图标加标题，有快捷键才写在右边。不排纯文字按钮。
4. **控件不重复。** 侧栏开关只留系统那一个，不另画 `sidebar.left`。新建、设置各出现一次。
5. **不拿占位冒充内容。** 缩略图、模板、预览必须是真实渲染。模板必须是不同的树，缩略图按各自结构画，不把同一张导图换色当十二个模板。
6. **浅色和深色都要看过。** 不许写死一片白或一片黑，深色下变成刺眼白卡片。
7. **新功能补一行冒烟。** 写进 `docs/SMOKE.md`。没在设备上点通之前，状态保持「未通」。
8. **新功能先对性能预算。** 提案时对照 `docs/PERF-BUDGET.md`，不许「以后再优化」。PR 描述里写三行「性能影响」：内存、帧率、包体各一行。缺一行，审查直接阻断。
