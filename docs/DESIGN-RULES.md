# 设计规矩

以后改界面先对照这里。和冒烟冲突时，冒烟优先。

1. **一个功能一个可见入口。** 快捷键不算入口。设置在宽屏只走侧栏「设置」，窄屏只走设置页签。首页不再放齿轮。⌘, 可以留。
2. **每个全屏页面都能离开。** 编辑器左上返回在 Mac、iPad、iPhone 都在。Zen 有退出。
3. **工具栏先用图标。** 撤销、重做、删除、插入、分享、更多用 SF Symbol，无障碍名称用中文。菜单行是图标加标题，有快捷键才写在右边。
4. **控件不重复。** 侧栏开关只留系统那一个，不另画 `sidebar.left`。新建、设置各出现一次。
5. **不拿占位冒充内容。** 模板必须是不同的树，缩略图按各自结构画，不把同一张导图换色当十二个模板。
6. **新功能补一行冒烟。** 写进 `docs/SMOKE.md`。没在设备上点通之前，状态保持「未通」。
