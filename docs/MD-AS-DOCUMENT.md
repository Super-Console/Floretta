# Markdown 作为一等文档类型（MD-as-Document）

> 状态：**已通过（Censor）** — 2026-11-10 复审通过；可进 S0/S1  
> 范围：定义 md 一等文档的数据映射、失败语义与 UI **验收合同**；实现归属见 §9（Interop 不碰 Apple 端 UI 实现）。  
> 关联：`docs/FORMATS.md`、`docs/FORMAT-FOR-AI.md`（S0 草案）、`docs/PERF-BUDGET.md`。

## 1. 定位

Floretta 采用 **双格式、同一文档模型的两种投影**：

| 投影 | 文件 | 角色 |
|---|---|---|
| 完整工程 | `.floretta` | 权威存储：附件、颜色、位置、关系线、便签、折叠、左右侧等全部模型字段 |
| 纯结构投影 | `.md` | 可直接打开 / 编辑 / 保存的一等文档；只承载 **层级 + 文字**（可选备注与 YAML front-matter） |

二者映射到同一棵 `MindMapDocument`（及会话态），不是「导入再另存」的临时转换。

**硬边界：** `.md` **绝不假装保真**。不能表达的字段：不写入文件、不在 md 会话里留下可再写回文件的残渣。从 `.floretta` 另存/切换到 `.md` 时，丢失项必须可说明；从 `.md` 打开时，这些字段保持模型默认空值，直到用户「升级为完整工程」。

## 2. 目标与非目标

### 2.1 目标

1. 用户可像打开 `.floretta` 一样直接打开 `.md`，编辑后 ⌘S / 自动保存写回 **同一个** `.md`。
2. 顶部常驻标注 **「Markdown 模式」**，并说明不含附件、颜色、关系线、自由位置与折叠态。
3. 保存只序列化规格允许的内容；禁止把颜色/附件/关系线/位置等塞进 HTML 注释、隐藏 front-matter 键或旁路 sidecar。
4. 层级映射定死（见 §4）；与旧「仅标题导出」路径严格分离，**打开/保存 `.md` 永远以嵌套列表为主**。
5. md 模式下插入附件、上色、连线 **一律置灰**，并给出原因文案。
6. 提供 **「升级为完整工程」**：经系统另存为 `.floretta`（当前树 + 默认视觉字段）。
7. md 模式 **没有稳定节点 UUID**；对 AI 用路径定位（如 `root/3/1`），写入 `docs/FORMAT-FOR-AI.md`。

### 2.2 非目标（本期不做）

- 在 `.md` 里编码 XMind/FreeMind 样式、图标、云、加密块。
- 双向无损 round-trip：`.floretta` → `.md` → `.floretta` 恢复颜色/附件/关系线。
- 把任意 CommonMark / GFM 扩展（表格、任务列表勾选状态持久化、脚注）全部吃进模型。
- Interop 直接改 Apple 端 UI 代码（§3 为验收合同，由 Floretta 轨道实现，见 §9）。

## 3. UI / 交互硬要求（验收合同；实现归属 Floretta）

### 3.1 常驻标注

- md 文档编辑器顶栏（或画布上方安全区）常驻条带，文案 **必须** 包含：
  - 标题：**Markdown 模式**
  - 说明：本文件只保存层级与文字；**不含附件、颜色、关系线、自由位置与折叠态**。
- 该条带不可被用户关掉；升级为 `.floretta` 并切换文档后消失。

### 3.2 置灰能力

下列入口在 md 模式下 **disabled**，并带说明（`help` / `accessibilityHint` / 轻提示，三选一或并用，文案统一）：

| 能力 | 置灰原因（建议文案） |
|---|---|
| 插入附件 | Markdown 模式无法保存附件 |
| 节点上色 / 主题色 | Markdown 模式无法保存颜色 |
| 关系线 / 连线 | Markdown 模式无法保存关系线 |

其他完整工程专属能力（若产品后续暴露）：凡无法在 §4 映射表中落盘的，一律同样处理，禁止「可点但保存时丢掉」的假可用。

### 3.3 升级为完整工程

- 菜单 / 工具栏动作：**升级为完整工程**。
- 行为：打开系统另存面板，默认扩展名 `.floretta`；写入当前 `MindMapDocument` 的完整工程容器（附件字典为空、颜色/关系线/位置为模型默认）。
- 另存成功后：**询问**是否打开新 `.floretta`；**默认**保持当前 `.md` 不关。
- **禁止**不经另存确认、原地把扩展名改成 `.floretta`。
- **禁止**静默覆盖原 `.md`。

## 4. 层级与字段映射（定死）

### 4.1 文件形态

```text
---
任意: YAML
front-matter: 原样保留
---

# 可选：仅一级分区标题

- 根级节点 A
  - 子节点
    - 孙节点
- 根级节点 B

> 紧跟在某一列表项后的 blockquote = 该节点备注（可选）
```

### 4.2 解析优先级（读入）

1. 若文件以 YAML front-matter（开头 `---` … 下一 `---`）开头：**整块原文保留**在文档会话的 `markdownFrontMatter: String?`（或等价字段），**不解析进节点树**，保存时 **原样写回**（字节级不要求，但键序与内容以「用户未改则语义不变」为准；实现应尽量不改写未触碰的 front-matter 文本）。
2. **主体结构以嵌套列表为主：**
   - **无序标记（读入）：** 行首（缩进后）`-` / `*` / `+` + 至少一个空格，均识别为无序项。
   - **有序标记（读入）：** 行首（缩进后）`\d+\.` + 至少一个空格，同样读成无序节点（只进树结构，不保留序号语义）。
   - 若发生了 `*` / `+` / 有序 → 内部统一为无序树的规范化，打开时给 **一条非阻断提示**。
   - 缩进单位：**2 个空格** = 一层。Tab 读入按 **1 tab = 2 空格** 规范化；打开时给 **一条非阻断提示**。**不因 Tab 拒开。**
   - 兄弟顺序 = 文件中出现顺序 → `children` 顺序。
3. **标题作为可选一级分区（仅 H1）：**
   - 列表外 **恰好一个 `#`**（`# ` + text）可作分区根：`MindMapNode`，`text` = 标题文字，标志 `isMarkdownSectionHeading = true`；其后、下一分区标题之前的嵌套列表挂为其 `children`。
   - 列表外的 `##`–`######`：**打开失败**；报错 **必须含行号**。禁止当同级根、禁止当正文吞掉、禁止静默降级为 `#`。
   - 多个连续一级分区 → 多个 `document.roots`。
   - **禁止**用标题深度表达任意多级树的主路径；主路径永远是列表缩进。
4. **行内链接（硬规定）：**
   - 若整个列表项正文（trim 后）**恰好是一个** `[text](url)` → `text` + `link`。
   - 否则：整项写入 `text` 纯文本，**不解析**多个 link；`link` 为空。
5. 紧跟该列表项之后、下一列表项/标题/front-matter 之前的连续 `>` blockquote 行 → 该节点 `note`（去掉 `>` 前缀；保留行内换行）。
6. **空行：** 跳过。**显式空列表项**（如 `- ` / `* ` / `+ ` / `1. ` 且无正文）：保留 `text == ""` 节点（结构占位）。

### 4.3 写出（保存）

1. 先写保留的 front-matter（若有），再空一行，再写正文。
2. 若根带 `isMarkdownSectionHeading`：写 **恰好** `# ` + text（永远一级）；其子节点写嵌套列表。否则全部根写顶层列表。
3. 嵌套：**每层 +2 空格**；标记 **只写** `- `（不写 `*` / `+` / 有序）。
4. `note` 非空：在该列表项下一行起写 `> ` 引用；空备注不写。
5. `link` 非空且采用「单一链接」形态：列表项写成 `[text](url)`，按现有导出规则转义；否则只写纯文本。
6. **绝不写出：** 附件、颜色、关系线、画布坐标、折叠、左右侧、节点 UUID、任何 HTML 注释藏数据。

### 4.4 双向映射表

| Markdown | → 模型 | 模型 → Markdown | 说明 |
|---|---|---|---|
| YAML front-matter | `markdownFrontMatter`（不透明字符串） | 原样写回 | 不进节点；用户未改则保持 |
| 列表外恰好 `# ` | 分区根 `text` + `isMarkdownSectionHeading` | `# ` + text | **仅一级**；`##`+ 拒开 |
| `-`/`*`/`+`/`\d+.` 嵌套列表（2 空格一层；Tab→2 空格） | `children` 树 / 顺序 | **只写** `- ` + 2 空格 | **主层级** |
| 列表项纯文本 | `text` | 列表项文本 | |
| 整项恰好一个 `[text](url)` | `text` + `link` | 同形 | 多 link 不解析，整项纯文本 |
| 紧随的 `>` 块 | `note` | `>` 块 | 可选 |
| 显式空列表项 | `text == ""` | `- ` | 结构占位；纯空行跳过 |
| （无） | `id`（UUID） | **不写** | 临时 UUID 仅内存；AI 用路径 |
| （无） | 附件 | **不写** | UI 置灰 |
| （无） | 颜色 / 样式 | **不写** | UI 置灰 |
| （无） | 关系线 | **不写** | UI 置灰 |
| （无） | `position` / `side` / `isCollapsed` | **不写** | 打开时模型默认；不留残渣 |

### 4.5 与现行 `FlorettaMarkdown` 导出的关系

| 项 | 现行（P2-2） | 本规格 |
|---|---|---|
| 角色 | 仅导出 | 一等文档读写 |
| 主层级 | 标题深度 `#`×n | **嵌套列表** + 可选 **仅 H1** 分区 |
| 导入 | 无 | 有 |
| front-matter | 无 | 原样保留 |
| 保真承诺 | 导出丢折叠/侧/坐标 | **明确不保真**；UI 与保存双约束 |

**旧「纯标题导出」：** 保留为「导出为…」里的 **可选预设**；与 **打开/保存 `.md` 文档** 路径 **严格分离**。文档保存永远走本规格嵌套列表映射。

## 5. 路径定位（给 AI / 给 FORMAT-FOR-AI）

md 模式不把节点 UUID 当作文件内稳定身份（保存也不写 ID）。**禁止**用临时 UUID 当作 AI 地址。

### 5.1 路径语法

- 文档森林：`root` 指整棵打开文档的根列表（`document.roots`）。
- 子节点：`root/<i>/<j>/...`，索引为 **从 0 起的兄弟序**（与文件中列表顺序一致）。
- 例：`root/3/1` = 第 4 个根（索引 3）下的第 2 个子节点（索引 1）。
- 分区标题根与普通根同一套索引；不因写了 `#` 而改变路径算法。
- **插入 / 删除 / 移动** 后，受影响兄弟及其后继的路径索引立即失效；调用方必须以最新树重算路径，不得缓存旧路径当稳定 id。

### 5.2 读写语义（须写入 `docs/FORMAT-FOR-AI.md`，S0 用同一例子写清）

| 操作 | 含义 |
|---|---|
| `get text\|note\|link @ path` | 读字段 |
| `set text\|note\|link @ path` | 写字段（仅这三项可经 AI 在 md 模式持久化） |
| `insert child\|sibling @ path` | 插入空或带 text 的节点 |
| `delete @ path` | 删除子树 |
| `move @ from → to` | 调整父子/顺序（细节在 FORMAT-FOR-AI 展开） |

拒绝 AI 在 md 模式设置颜色、附件、关系线、position；返回明确错误码/文案，与 UI 置灰一致。

### 5.3 与 `.floretta` 的差异（摘要，详表放 FORMAT-FOR-AI）

| | `.floretta` | `.md` |
|---|---|---|
| 节点身份 | UUID | 路径 `root/3/1`（易变；插入/删除使后续索引失效） |
| 可持久化字段 | 全模型 | text / note / link / 结构 + front-matter |
| AI 写颜色等 | 允许（若产品开放） | 拒绝 |

## 6. 会话与残渣规则

打开 `.md` 时：

1. 解析 → `MindMapDocument` + `markdownFrontMatter`。
2. 为编辑分配 **临时** UUID（仅内存），**不得**在保存时写进 `.md`，**不得**作为 AI 路径别名对外暴露为稳定地址。
3. 颜色、附件、关系线、position、side、isCollapsed 使用模型默认；用户若通过任何漏洞改了这些字段，**保存 `.md` 时仍丢弃**，不得写残渣。
4. 脏标记只跟踪：树结构、text/note/link、front-matter 文本。

从 `.floretta` 「另存为 Markdown」或「以 Markdown 投影打开」：

- 投影时丢弃不能表达的字段；
- 若用户未升级回工程，那些字段不可恢复——须在第一次另存/切换时用一次说明（系统提示即可）。

## 7. 错误与拒绝

- 无法识别为列表 / **合法 H1 分区标题** / front-matter 的主体大段：打开失败，明确报错（对齐 FORMATS「导入失败必须明确报错」），禁止猜半棵树。
- 列表外 `##`–`######`：打开失败，报错含行号（见 §4.2）。
- Tab / `*` / `+` / 有序列表：按 §4.2 **规范化**，不拒开；用非阻断提示说明已规范化。
- 外部实体、HTML 注释藏数据：忽略注释内容且 **不** round-trip 藏匿字段。

### 8.2 断言

- 导入 → 导出 → 再导入：层级、顺序、text、note、link、front-matter 一致；写出仅含 `- ` 与合法 `# `。
- 导出文件中 **不出现**：UUID、颜色 token、附件路径、关系线、HTML 注释载荷、`##`+ 分区。
- UI 级（Floretta 轨道）：md 模式置灰三项 + 常驻「Markdown 模式」文案（含位置/折叠说明）存在。
- 升级：另存 `.floretta` 后可用完整工程打开，树文本一致；默认不关 `.md`。
- **性能（S1）：** 约 1000 节点级 `.md` 打开应符合 `docs/PERF-BUDGET.md`（打开 &lt;1.5s 量级，不计无关解码）。禁止把「以后再优化」写进实现 PR 当验收豁免。
