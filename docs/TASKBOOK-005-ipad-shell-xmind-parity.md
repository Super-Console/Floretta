# TASKBOOK-005 — 首页与画布外壳（对齐 XMind iPad）

参考图：`docs/design/xmind-ipad-ref/01..13-*.jpg`（Timmy 提供的 XMind iPad 实拍，**只作视觉参考，不要复制其代码**）。

**与 TASKBOOK-004 的关系**：004 定义了首页/缩放/Zen 的骨架，本文件把结构细化并**取代 004 中冲突的部分**。
系统控件约束不变：**自绘控件仍需报批**；本文所有"容器"用系统形状+材质实现，按钮一律系统 `Button`+SF Symbol。

## A. 首页（Library）——参考 01/02/03 图

结构（iPad，`regular` 宽度）：

```
┌ 侧边栏(可收起) ┬────────────── 主区 ──────────────┐
│ ⚙︎  ⇤          │            最近              ＋ 👑 ▦ ⋯ 🔍 │
│ ◷ 最近         │                                       │
│ ▣ 新建导图      │        [空状态插画]                    │
│ 本地导图        │        这里还没有导图。                 │
│  📁 从文件应用打开│        现在是创建一个好的时机。           │
│  ☁️ 从 iCloud 打开│        [ 新建导图 ]                    │
│  💻 我的 iPad ▸ │                                       │
│                │                                       │
│ 👤 登录         │                                       │
└────────────────┴───────────────────────────────────────┘
```

要求：

- 侧边栏用 `NavigationSplitView` 的 `sidebar`，条目用系统 `List`（含 `.listStyle(.sidebar)`）；
  **不要自绘圆角选中态**——XMind 那个灰色胶囊由系统选中态实现。
- 分区标题（"本地导图"）用 `Section` header。
- 顶栏右侧按钮顺序照抄：**新建(+)、升级(皇冠，可先隐藏)、视图切换(宫格)、更多(⋯)、搜索**，全部 `Button` + SF Symbol。
- 主区标题为「最近」（大标题样式），列表为空时显示空状态：插画（可先用 SF Symbol `pencil.and.ruler` 近似）+ 两行文案 + 一个 `.borderedProminent` 胶囊按钮「新建导图」。
- 「从文件应用打开」用 `.fileImporter`；「从 iCloud 云盘打开」用 `.fileImporter`（iCloud 容器）或省略并合并为一个入口——**本期只保留一个「从文件 App 打开」入口**，不要做两个假入口。
- 有内容后：网格卡片（文件名 + 修改时间 + 缩略图位），`LazyVGrid`。

## B. 新建页（modal）——参考 04/05 图

- 全屏 `sheet`，大标题「新建」，左上关闭按钮，右上存储位置选择器（本期固定"我的 iPad"，显示但不切换）。
- **分区顺序照抄**：`基本` → `知识管理` → `会议和计划` → `学习和教育`。
- 每个分区右上角「全部」（本期可点击但只显示"敬请期待"，或直接隐藏——二选一，不要做假页面）。
- 模板卡片：缩略图 + 名称；卡片用 `Button` 包裹 `RoundedRectangle` + `Image`，**不自绘阴影蒙版**。
- 付费模板（带锁 + 下载箭头）：**本期全部做成不可用并隐藏锁**，不实现内购。绝不做假付费流程。

### B-1 六种布局（重要，控制范围）

「基本」区六个卡片代表**六种结构布局**：

| 名称 | 结构 | 本期 |
|---|---|---|
| 思维导图 | 中心主题 + 左右双侧分支 | **必做（已有 LayoutEngine）** |
| 逻辑图 | 中心 + 同侧向右分支 | 只记录，后续 |
| 括号图 | 纯横向层级括号 | 只记录，后续 |
| 组织结构图 | 自上而下树 | 只记录，后续 |
| 树形图 | 自上而下 + 折线 | 只记录，后续 |
| 时间轴 | 线性 | 只记录，后续 |

**本期只实现「思维导图」一种**，其余卡片点击后提示"该布局将在后续版本提供"。
不要为了六个缩略图去写六套布局引擎。

## C. 画布态 chrome ——参考 02/06/07 图

| 位置 | 内容 | 实现 |
|---|---|---|
| 左上 | 返回 + 文档名 + ▾ | `NavigationStack` 返回 + `Menu` 承载文件操作 |
| 顶部中央 | 浮动工具条：撤销、大纲、关系线、粘贴、新建(+) | `HStack` 包在 `Capsule().fill(.ultraThinMaterial)` 里；按钮为系统 `Button` |
| 右上 | 分享、投屏、样式刷、更多 | 系统按钮，投屏/样式刷本期置灰 |
| 左下 | 大纲面板开关 | 系统按钮，切换左侧 `.inspector` 或 overlay |
| 右侧 | 检查器 | iOS 17 原生 `.inspector`，三个 `Picker`(segmented) 分页 |

**浮动工具条是唯一需要"像样"的自定义容器**：只允许系统材质 + 系统形状，不允许渐变描边、发光、自定义阴影。若 Timmy 要更花的效果，另行报批。

## D. 检查器三个 tab ——参考 07 图

- `样式`：主题（形状 / 填充样式 / 填充颜色 / 长度滑块+数值）、边框（样式 / 宽度 / 颜色）、文本（字体 / B I S U / 大小 / 颜色）。
  全部用系统 `Picker`、`ColorPicker`、`Slider`、`Toggle`、`Menu`。
- `演说`、`导图`：本期只放占位（"尚未实现"），**不做假功能**。

节点颜色是本项目的数据字段，不是控件，可保留 XMind 那种高饱和配色。

## E. 菜单 ——参考 06/08/09/10 图

- **文件菜单**（文档名 ▾ 展开）：文档名 + "Floretta 文件 · xx KB" 副标题 → 重新命名 / 设置密码(置灰) / 风格化分享(置灰) / 导出 / 保存至 / 打印。
- **导出子菜单**（本期已实现的）：`.floretta`、`.mm`、`.opml`、Markdown、PNG、PDF。
  **不要**出现 Word/Excel/Calendar(Task) 这些我们没实现的选项——宁缺勿假。
- **更多菜单**：查看模式、新建画布、演说(置灰)、**ZEN**、查找、反馈(置灰)。「立即升级」「投屏至图库」「方程帮助」不显示。
- **选中文字工具条**：剪切 / 拷贝 / 粘贴 / 全选 / 拷贝样式 / 生成想法(置灰) / AI 工作分解(置灰)。
  前五项用系统 `EditMenu` / `UIMenu` 原生能力，不要自绘气泡。

## F. 验收

1. iPad 横屏：侧边栏可收起/展开，主区标题「最近」，空状态与 03 图一致。
2. 点「新建导图」→ 新建页 sheet，四个分区和六个布局卡片都在；点非思维导图布局提示"后续版本"。
3. 建立思维导图后进入画布：顶部浮动工具条、右上四按钮、左下大纲开关都在。
4. 右侧 `.inspector` 三 tab 可切换，样式页三类控件能改节点颜色/字号并实时生效。
5. 文件菜单、更多菜单、导出菜单只出现本文件列出的项，**没有假选项**。
6. Zen 模式生效（沿用 004 的 P5-5）。
7. macOS 端：不照搬浮动工具条，用窗口工具栏 + 菜单栏命令，结构对应。
8. 双编通过；现有测试全掉不许。
