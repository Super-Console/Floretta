# TASKBOOK-005 — iPad 外壳对齐 XMind（首页 / 侧栏 / 检查器 / 菜单）

参考图在 `docs/design/xmind-ipad-ref/`（13 张，来自 Timmy 的 iPad 实拍 XMind）。
**看图，不要凭记忆**。每张图对应下面一个区块。

## 0. 硬约束（先读这条）

- **只用系统控件**：`Button` / `Picker` / `Slider` / `Toggle` / `List` / `NavigationSplitView` / `.inspector`。
- 右侧检查器**用系统 `.inspector`**（iOS 17+/macOS 14+），不要自造面板、不要自绘圆角和阴影。
  苹果有这个 API，右侧栏完全可以保留 —— 之前说"不能自造"指的是不要手绘，不是不要栏。
- 彩色分支（节点填充色）属于**文档内容**，必须支持，它不是 UI 控件。
- 浮动工具条允许用系统材质做容器（`.ultraThinMaterial` + `Capsule`），但里面的按钮必须是系统 `Button` + SF Symbol。
  任何渐变、投影、自绘图形要先报批。
- 每批双编（macOS test + iOS build）过再 push。

## 1. 首页「最近」（图 11 / 13）

顶栏（`NavigationStack` + `toolbar`）：

- 左：侧栏切换按钮（图 13 展开后变成「齿轮 + 侧栏」两个按钮）
- 中：标题 `最近`（居中，不是大标题；大标题只在「新建」页出现）
- 右：`+`（新建）、皇冠（订阅）、网格（模板库）、`⋯`（更多）、放大镜（搜索）

空状态（图 11）：居中插画 + 两行文案「这里还没有导图。」/「现在是创建一个的好时机。」+ 白色胶囊按钮「新建导图」。

侧栏（图 13，`NavigationSplitView` sidebar）：

```
最近            ← 选中态，带时钟图标
新建导图        ← 加号图标
本地导图        ← 分组标题（小号灰字）
  从文件应用打开   ← 蓝色文件夹图标
  从 iCloud 云盘打开 ← 云图标
  我的 iPad       ← 平板图标
（底部）登录 + 头像
```

要点：
- `从文件应用打开` 用 `.fileImporter`，`allowedContentTypes` 只列 `.floretta/.mm/.opml/.md`
- `我的 iPad` 是本地目录浏览（文档目录），不扫全盘
- 底部「登录」区域在没有账号体系时显示为禁用占位，不要假装已登录

## 2. 新建 / 模板库（图 12，另见图 8、9、10）

- 左上 `X` 关闭；右上位置菜单 `iCloud 云盘 ⌄`（选择保存位置）
- 大标题 `新建`
- **Xmind AI** 分区：5 个横向卡片
  - 一键生成 / 待办事项 / 工作分解 / 图片转思维导图 / 演说视频（右上角「实验室」标签）
- **基本** 分区：思维导图 / 逻辑图 / 括号图 / 组织结构图 / 树形图 / 时间轴…（右侧「全部」入口）
- 其余分区：知识管理 / 会议和计划 / 学习和教育 / 项目管理 / 娱乐和生活 / 分析和决策 / 创造力
- 卡片：缩略图 + 名称；付费模板右上角锁标 + 右下角下载箭头

**本期范围（重要）**：只实现「基本 → 思维导图」这一种模板的创建，其余卡片**显示但置灰/标"即将推出"**，
不许画一个假的模板库然后点不动也不提示。AI 卡片同理：显示 + 点击提示"未开放"。

- 浮层标题 `大纲` + 全屏/关闭按钮
- 条目按层级缩进，可展开折叠

## 5. 文件菜单（图 6）

顶部：文档名 + 类型 + 大小（`思维导图 4 · Xmind 文件 · 64 KB`）
菜单项：重新命名 / 设置密码 / 风格化分享 / 导出 / 保存至 / 打印

我们的映射（不是每一项都做）：

| XMind | 我们 |
|---|---|
| 重新命名 | 做（改文档标题） |
| 设置密码 | 不做（本地优先，无加密需求） |
| 风格化分享 | 不做 |
| 导出 | 做（见第 7 节） |
| 保存至 | 做（`.fileExporter` 另存为） |
| 打印 | macOS 做（`NSPrintOperation`），iOS 不做 |

## 6. 更多菜单（图 5）+ 导出子菜单（图 3）

更多：查看模式 / 立即升级 / 新建画布 / 投屏至图库 / 演说 / **ZEN** / 查找 / 方程帮助 / 反馈

映射：**只做 ZEN、查找、新建画布**；其余显示为禁用项或直接不出现（不许出现点不动的死项）。

导出（图 3）：Xmind 文件 / JPEG / PNG / PDF / Markdown / Word / Excel / OPML / Excel(Task) / Calendar(Task)

映射：**只列我们真能导的** —— `.floretta` / PNG / PDF / Markdown / OPML / `.mm`。
不支持的格式**不要出现在菜单里**。

分享面板（图 3 下）：邀请协作者 / 创建演说视频 / 风格化分享 / 导出 / 保存至
→ 我们只保留「导出」「保存至」。

## 7. 右侧检查器（图 4）

系统 `.inspector`，三个 tab（`Picker` segmented 样式换内容，或系统的 Inspector tab）：

**样式**
- 主题：形状（Picker：矩形/圆角/胶囊/无边框）、填充样式、填充颜色（`ColorPicker`）、长度（`Slider` + 数值，如 183px）
- 边框：样式、宽度（Slider）、颜色
- 文本：字体（Picker）、B/I/S/U（`Toggle` 组）、大小（Picker/Slider）、颜色（ColorPicker）

**演说 / 导图**：本期先放占位（"即将推出"），不做假交互。

数据落点：填充色/边框/字号必须写进文档模型并随文件保存，**不能只是视图状态**。

## 8. 文本选中工具条（图 7）

剪切 / 拷贝 / 粘贴 / 选择 / 拷贝样式 / 生成想法 / AI 工作分解

映射：只做**剪切/拷贝/粘贴/选择**（系统 `EditMenu` 或 `contextMenu`）。
`拷贝样式/生成想法/AI 工作分解` 不做，也不显示。

## 验收

1. 冷启动 → 首页「最近」空状态（图 11），侧栏可展开（图 13）。
2. 点「新建导图」→ 新建页（图 12），「基本 → 思维导图」能真的创建并进入画布。
3. 画布双端打开，右下角出现系统 `.inspector`，改填充色后**保存→重开颜色还在**。
4. Zen 模式隐藏所有按钮，Esc/双击退出。
5. 菜单里出现的每一项都能点；不能点的项不出现。
6. 双编通过，测试全绿，新增行为有测试。
