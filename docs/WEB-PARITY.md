# Floretta App ↔ Web 功能同步表

网页目标：`/floretta/app/`。网页状态根据 FlorettaWeb 最近合并的 PR #10（主题同步）与 #11（工程文件导入导出），并对照该仓库 `docs/WEB-PARITY.md`、`FEATURES.md` 整理；App 状态对照本仓库 `docs/FEATURES-CHECKLIST.md`。更新日期：2026-11-11。

网页状态用语：**已同步**、**部分**、**不做**、**未核实**、**不适用**。App 两列描述原生端能力；网页不因「不做」而视为缺陷。

| 功能 | Mac | iOS | 网页 | 说明 |
|---|---|---|---|---|
| 新建、打开、保存 `.floretta` | 支持 | 支持 | 已同步 | 网页读写本地工程 ZIP；PR #11 新增导入导出。网页可用 File System Access；不支持时使用文件选择和下载。 |
| 大纲编辑、节点增删、拖拽重排 | 支持 | 支持 | 已同步 | 网页有 Tab/Enter 编辑和拖动调整层级。 |
| 撤销 / 重做 | 支持 | 支持 | 已同步 | 网页本地操作。 |
| 缩放、画布、大纲与检查器 | 支持 | 支持 | 已同步 | 网页有八档缩放、画布、大纲、形状/填充/文字检查器；小屏改用浮层布局。 |
| 沉浸模式 | 支持 | 支持 | 已同步 | 网页 Zen 隐藏顶栏、大纲和检查器；不是原生窗口模式。 |
| 主题 / 纸张配色 | 支持 | 支持 | 已同步 | PR #10 对齐纸色、节点填充/描边、连接线与字体层级。 |
| `.xmind` 导入导出 | 支持 | 支持 | 已同步 | 网页支持 `content.json`；XMind 8 仅 `content.xml` 的限制见网页格式说明。 |
| `.opml`、`.mm`、`.md` 导入 | 支持 | 支持 | 已同步 | 网页支持这些格式导入；实际保真字段仍以各格式规格为准。 |
| `.floretta` / `.xmind` / `.md` / PNG 导出 | 支持 | 支持 | 已同步 | 网页在浏览器本地生成，不上传。 |
| PDF 导出 | 支持 | 支持 | 部分 | 网页输出单页 JPEG 图像 PDF；不是 macOS 打印面板。 |
| 工程附件与附件容器 | 支持 | 支持 | 部分 | PR #11 增加工程 ZIP 与 `assets/<sha256>.<ext>` 读写、附件字节原样保留及图片预览。网页 UI/编辑能力不等于原生附件能力；元数据兼容仍须真实 App 文件验证。 |
| 任意文件附件 Quick Look | 支持 | 支持有限 | 不适用 | Quick Look 是 Apple 平台能力；网页可用浏览器图片预览等效，不提供 Quick Look。 |
| 系统材质 / 液态玻璃 | 原生材质 | 原生材质 | 部分（网页不适用/以毛玻璃等效） | 网页只能用 CSS `backdrop-filter` 等效，并按能力退化为纸色；不等同系统液态玻璃。PR #10 同步的是纸张主题，不代表网页获得原生材质。 |
| macOS 多窗口、窗口菜单 | 支持 | 不适用 | 不适用 | 网页应用运行在浏览器标签/窗口中，不实现 App 的多窗口文档同步语义。 |
| Finder Quick Look 插件 | 支持 | 不适用 | 不适用 | Finder 扩展仅属于 macOS。 |
| 语音输入 / 系统分享扩展 | 支持 | 支持 | 不适用 | 分享扩展与系统语音入口依赖 Apple 平台；网页的浏览器输入不等同系统扩展。 |
| 本地文件监听、打印面板 | 支持 | 不适用 | 不做 | 网页仓库明确列为不做；浏览器下载/选择文件不是持续监听。 |
| MCP / CLI | 支持 | 不适用 | 不做 | 网页没有 MCP；本机工具与网页编辑器职责不同。 |
| 工程文件导入 / 导出（网页独有交付路径） | 原生文件入口 | 原生文件入口 | 已同步 | 网页侧以浏览器方式操作 `.floretta`；PR #11 提供 ZIP 容器处理。不同平台的文件授权/保存行为不完全相同。 |

## 同步与未核实边界

- 网页最近的相关变更为 FlorettaWeb PR #10、#11，均已合并；此表不是对每种浏览器、每个格式样本的重新端到端验收。
- PR #11 说明没有真实 App 生成的 `.floretta` 样本，且新建导出时 `metadata.json` 写 `{}`；完整 App 打开兼容性未独立确认。不要把「网页具备读写」理解为所有扩展字段均已跨端验收。
- 本表是 App 仓库侧的同步副本；网页功能变化后应先核对网页仓库的 canonical parity 表及实现，再更新本表。
