# A27 — macOS Inspector 顶栏固定 AX 证据

> **本 PR 不修改检查器钉住逻辑；以下读数来自已安装的 1.0 build 8，仅作参考，不作为本 PR 的验收证据。**

## 结论：实现已存在，本 PR 未验证

build 8 的两态 AX 读数不相等，不能证明当前 PR 源码行为；当前源码 build 12 未能取得可枚举窗口，因此本 PR 未验证 A27。

- **有选中节点**：检查器「样式」分段控件的 AX `frame.minY = 184`（桌面坐标）。
- **未选中空态**：同一分段控件的 AX `frame.minY = 496.5`（桌面坐标）；AX 同时显示「选择一个主题」，确认处于空态。
- **未保存或提交证据截图；未取全屏截图（避免涉及用户主屏）**。AX 定位期间曾临时读取副屏目标窗口图像用于像素点击，未落盘。

**184 ≠ 496.5，因此这组实测不支持顶栏固定。** AX 树未暴露 `inspector.header` 容器，仅暴露其「样式」「演说」「导图」分段子控件；两个数字都测的是该可见子控件，不是容器本身。

窗口通过 `set_window_frame` 设在副屏坐标 `x=2600, y=120, width=1100, height=900`。读数来自 `/Applications/Floretta-macOS.app`（版本 `1.0`、build `8`），不是本分支刚编译的 build `12`；因此这两个数字是有效的旧安装版 AX 观测，但**不能作为当前分支代码的最终验收证据**。当前分支的 `Floretta-macOS` 目标已成功编译；从 DerivedData 启动的 build `12` 进程未向 CUA 暴露可枚举窗口（`list_windows` 返回空），故无法在该进程中复测。A27 对当前分支仍未验收。
