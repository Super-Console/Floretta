# 画布性能结果

目标（不许下调）：

- 500 节点文档**平移**平均 FPS ≥ 55、最低 ≥ 45
- 200 节点不得低于 58

测量协议、夹具、打点方式与 `CANVAS-PERF-BASELINE.md` 相同。时间均为 CST（Asia/Shanghai）。

## 结论

**达标。** 最终确认轮（D2a / D2b，2026-11-12 18:27:01–18:30:57 CST）：

- macOS 500 平移：两轮都是平均 120、最低 120（最长帧 14.1 / 12.2 ms）
- macOS 200 平移：两轮都是平均 120、最低 120
- iPad 500 平移：两轮都是平均 59.7、最低 58（最长帧 33.3 ms）
- iPad 200 平移：D2a 平均 60、最低 60；D2b 平均 59.7、最低 58

拖动在修完同一类问题后也回到了屏幕刷新率（macOS 约 119 FPS，iPad 约 60 FPS）。下面按项说明数据，不把未支持的改动算进去。

## 逐项排除（每项单独关，在 D1 之上测 macOS 500）

临时开关 `-FlorettaPerfOff` 只用于这些隔离轮，**没有进产品提交，也没有进本 PR**。日志：`docs/reviews/perf-logs/mac-X1-{none,A,B,C,E,F}-500.json`，本机 `/tmp/canvasperf/mac-X1-*-500.out`。时间：2026-11-12 18:19:53–18:21:36 CST。

| 项 | 做法 | 平移 平均/最低/最长帧 | 拖动 平均/最低/最长帧 |
| --- | --- | --- | --- |
| 对照（D1，开关全开） | 无 | 120 / 120 / 9.6 ms | 3.7 / 2 / 292.9 ms |
| A 玻璃与材质层 | 关掉 `glassEffect` / `appleGlassChrome` 的镀层，并关掉 `backgroundExtensionEffect` | 120 / 120 / 10.4 ms | 4.2 / 4 / 257.8 ms |
| B 点阵背景 | 不调用 `drawGrid` | 120 / 120 / 12.9 ms | 3.6 / 2 / 308.3 ms |
| C 统计计算 | 溢出菜单的主题/字数/字符数固定返回 0，不做遍历 | 120 / 120 / 11.8 ms | 3.8 / 2 / 283.3 ms |
| E 文本测量 / 绘制 | 节点标题不画字 | 120 / 120 / 11.6 ms | 3.9 / 2 / 283.3 ms |
| F 阴影 | 关掉节点 `GraphicsContext` 阴影滤镜 | 120 / 120 / 9.9 ms | 3.9 / 2 / 283.3 ms |

A / B / C / E / F 都没有把 500 节点平移从 120 拉开，也没有把拖动从约 4 FPS 拉起来。它们不是这个文档上的平移瓶颈，C 也不是拖动瓶颈，因此**没有**为此做统计缓存重构，也没有降低玻璃或点阵质量。

**D 布局抖动**才是平移/缩放热点：`DocumentEditor` 在自己的 `body` 里读了 `camera.viewport`（`onChange`）和 `camera.chrome.zoomPercent`（macOS 缩放按钮）。每帧平移或缩放开了视口，整棵编辑器 `body` 重跑；macOS 上 SwiftUI 接着每帧重建 `NSToolbar`（`ToolbarBridge.updateStorage`）。把这两处读取挪到独立子视图之后，平移/缩放回到刷新率，但拖动仍在约 3–4 FPS（见 D1 列）。

拖动的同类原因：每帧 `document = CanvasPlacement.movingNode(...)` 改整份文档，编辑器 `body` 和工具栏再次全量更新，布局缓存也全部失效。改为在 `CanvasCamera.liveNodeOrigin` 上叠一帧中的原点，松手再写入文档。这与 D1 是同一类改动（不要让每一帧的画布交互打穿编辑器图），数据见 D2 列。

### 关于 iPad 200 节点平移曾低于 58

D1 两轮 iPad 200 平移为平均 56.7 / 54.0、最低 40 / 34，当时未达「不得低于 58」。平移路径在 D2 **没有再改**（平移从来不写文档）。按任务要求没有只保留最好的一轮，并把这两轮路径留在 `docs/reviews/perf-logs/ipad-D1{a,b}-200.json`。随后用同一协议又跑了两轮（D2a / D2b）：平均 60 / 59.7，最低 60 / 58，最长帧 18.7 / 33.3 ms。以这两轮确认轮为准，**200 节点平移现已不低于 58**。D1 那两轮长帧更像是当时模拟器负载下的抖动（同一次 D1 里 500 节点平移已经是 59.7 / 58）。
